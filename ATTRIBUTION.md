# Attribution

## CleanYourTV, the original project

CleanYourTV Extended is an independent, extended project inspired by **CleanYourTV**:

- Original repository: <https://github.com/Gathin23/cleanyourtv>
- Author: **Gathin23** (<https://github.com/Gathin23>)
- License: MIT
- A copy of the original license is in [`licenses/CleanYourTV-MIT.txt`](licenses/CleanYourTV-MIT.txt).

The original CleanYourTV is a guide, prompt, toolset and minimal launcher for safely debloating an
Android TV. If you want to disable preinstalled packages on your TV, follow the original project's
`PROMPT.md` and its safety rules. This repository does not contain its debloat lists, scripts or
automation.
